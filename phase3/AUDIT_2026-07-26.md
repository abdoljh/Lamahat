era-gated last resort) and steers thematic beats to "timeless".

## NEW finding — script/narration divergence (word 407)

The narration (and word_timings.json) says
«أم ينضم إلى صفوف الثورة العربية ضد الحكم العثماني؟» where every stored
`main_script.txt` says «أم ينحاز إلى شعبه العربي الذي يحلم بالحرية؟».
One revised sentence → every later word is offset by one token (652 vs
651).  The rendered cut is safe (plan quotes match the audio), but any
future align/plan run mixing the revised script with the old narration will
misalign the last third of the film.  **Rule: after any script edit, either
re-synthesize the narration or revert the script — never mix.**
P7.2's length-mismatch guard degrades gracefully here (falls back to
token-tail punctuation), by design.

## Follow-up (2026-07-27) — fourth-screening run audited

The P7 total solution ran (82 shots, 80 sentence captions, whisperx,
vision on) but the user judged it no better.  Three causes found:

1. **Photo-bank assignments 100 % discarded by a parsing bug.**  Sonnet
   assigned 27 bank photos to shots but returned keys as `"shot 2"`;
   `int("shot 2")` raised and every assignment was dropped with only a
   per-key warning.  This bug ate the bank in BOTH screenings.  Fixed:
   the validator now extracts the integer from any key shape, prebuild
   prints a loud banner + writes `PHOTO_BANK_NOT_ASSIGNED.txt` when a
   populated bank yields zero assignments.
2. **Cuts improved 84 % → 67 % mid-sentence — not enough.**  The ±0.9 s
   snap window was too timid.  Now a hard grid: ±2.6 s to a sentence
   end, ±1.2 s to a clause end, monotonic walk.  Replayed on the real
   82-shot plan: 54 → 33 mid-sentence cuts; a fresh plan compounds the
   prompt and the grid.
3. **Portraits collapsed 9 → 3** — the P7.3 "prefer timeless" guidance
   over-corrected.  The prompt now carries a biography portrait floor
   (6–10 protagonist portraits; timeless metaphors must not displace
   the people of the story).

Also confirmed: the narration is authoritative (it never says "ينحاز");
whisperx aligned 651/651 tokens, so the script mismatch is not a
blocker for rendering.  Captions were OFF in both screenings — the
sentence-caption track has not yet been seen on screen.
